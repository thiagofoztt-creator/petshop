# petshop
# 🐾 Bichano's Pet Shop

Site completo para pet shop desenvolvido com Python e Flask, 
com loja online, sistema de agendamento e pagamento via Pix com QR code.

## ✨ Funcionalidades

- 🛒 Loja online com compras integradas
- 📅 Agendamento de banho e tosa
- 👥 Gerenciador de clientes
- 💳 Pagamento via Pix com QR code
- 📱 Design responsivo para mobile e desktop
- 📞 Atendimento via WhatsApp integrado

## 🚀 Tecnologias utilizadas

- Python 3
- Flask
- Jinja2 (templates dinâmicos)
- HTML5 / CSS3
- JavaScript

## 💡 Diferenciais

Integração de pagamento via Pix com geração de QR code — 
funcionalidade que vai além do escopo acadêmico e demonstra 
capacidade de entregar soluções reais para clientes reais.

## 📦 Como rodar localmente

```bash
git clone https://github.com/thiagofoztt-creator/petshop.git
cd petshop
pip install flask
python app.py
```
